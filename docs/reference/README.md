# Materiais de referência

O conteúdo do aplicativo foi estruturado a partir de materiais fornecidos pela escola durante o planejamento do projeto.

Principais fontes usadas na modelagem:

- resumo oficial da Feira do Conhecimento;
- croqui geral da escola, com pátio, cantina/refeitório, quadra, quadra de areia e ligação entre prédios;
- mapa de blocos e salas, confirmando:
  - Bloco 1: salas 1, 2, 3, 4, 5 e 6;
  - Bloco 2: salas 7, 8, 9, 10, 11, 12 e 16;
  - Bloco 3: salas 14, 15, 13 e 17;
  - Portão de Entrada dos visitantes/pais e Portão da Secretaria;
  - passarela entre os blocos.

Os arquivos originais não são versionados neste repositório público. O repositório mantém apenas os dados derivados necessários ao funcionamento do aplicativo.
